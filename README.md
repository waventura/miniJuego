# ¡Aventura de Carlos y Mateo!

Mini-juego web 2D táctil (Single Player) diseñado en estilo **vectorial plano** para tablet Android de 8.7" (1340×800 horizontal 16:10), 100% offline con sonido sintetizado (Web Audio API) y empaquetado con Capacitor.

## Personajes Jugables
1. **Carlos** — *¡El Graduado!* (toga, estola dorada y birrete)
2. **Mateo** — *¡El Aventurero!* (ropa casual colorida y mochila)
3. **Piloto** — Piloto de Carreras con casco
4. **Súper** — Superhéroe con capa animada
5. **Astro** — Astronauta espacial con jetpack
6. **Dino** — Dinosaurio amigable con birrete

## Los 4 Mini-Juegos
1. **Pista de Carreras (Patio)**: Carrera lateral contra 3 CPU tocando `¡ACELERAR!` y `¡SALTAR!` para esquivar conos y charcos.
2. **Patio de Recreo**: Carrera de obstáculos (resbaladillas, pelotas, mochilas) recolectando estrellas y birretes.
3. **Salón de Clases**: Desliza el dedo (o usa `◀ IZQ` / `DER ▶`) para atrapar lápices, libros, manzanas y diplomas.
4. **Escalada a la Montaña**: Sube por plataformas saltando hasta la cima para plantar la bandera de `¡Graduado!`.

## Cómo descargar e instalar el APK en la tablet Android
1. Entra a la pestaña **Actions** de este repositorio en GitHub.
2. Abre la ejecución más reciente de **Build Android APK**.
3. En la sección **Artifacts**, descarga `carlos-y-mateo-app-debug-apk` y descomprime el archivo `app-debug.apk`.
4. Copia `app-debug.apk` a la tablet Android y tócalo para instalarlo (habilita *Instalar apps de fuentes desconocidas* si Android lo solicita).
5. ¡Listo! Funciona **100% sin internet** en pantalla completa horizontal.
